# Contribuir a USB Recovery Tool 🤝

¡Gracias por tu interés en mejorar este proyecto! Toda contribución es bienvenida.

## ¿Cómo puedes colaborar?

1. **Reportar errores o bugs:**
   Si encuentras algún dispositivo o escenario donde el script no responda adecuadamente, abre un *Issue* en GitHub adjuntando:
   * Sistema operativo y versión.
   * Modelo y capacidad de la memoria.
   * Registro relevante (sin datos sensibles).

2. **Proponer mejoras o funciones:**
   * Soporte para más sistemas de archivos.
   * Traducción a otros idiomas (ej. inglés).
   * Nuevos métodos de diagnóstico de salud de hardware.

3. **Enviar un Pull Request:**
   1. Haz un *Fork* del repositorio.
   2. Crea una rama para tu función (`git checkout -b feature/nueva-mejora`).
   3. Realiza tus cambios y pruébalos con cuidado.
   4. Haz commit de tus cambios (`git commit -m 'Agregar soporte para...'`).
   5. Haz push a la rama (`git push origin feature/nueva-mejora`).
   6. Abre un *Pull Request* describiendo tus aportes.
